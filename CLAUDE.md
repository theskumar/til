# CLAUDE.md — AI Assistant Guide for theskumar/til

## Project Overview

This is a personal **TIL (Things I Learned)** repository — a curated knowledge base of technical
learnings with an automated static site and RSS feed. It is inspired by
[jakelazaroff/til](https://github.com/jakelazaroff/til/).

- **Content language:** Markdown
- **Automation language:** JavaScript (Node.js)
- **CI/CD:** GitHub Actions (`.github/workflows/build.yml`)
- **RSS:** Published at `https://saurabh-kumar.com/til/rss.xml`

### No standalone articles

TIL holds dated notes only. Standalone articles were retired in Oct 2026.
Long write-ups go to the Writing section of saurabh-kumar.com
(`content/blog/` in the main site repo). Short ones are notes in `til.md`.
`RETIRED_ARTICLES` in `build-site.js` writes a redirect stub for each old
article URL.

## Content Conventions

### Adding content

**Quick note** — append a dated bullet to `til.md`:

```
- DD Mon YYYY. Your note here.
  Optional continuation line (indent with exactly 2 spaces).
```

A note can carry a fenced code block. Indent every line of it by 2 spaces,
and leave no blank lines inside the note.

Push to `main` and CI automatically builds the site and deploys to GitHub Pages.
For local preview: `npm install && node build-site.js && npx http-server _site -p 8787`

### Parser details
- Date regex: `/^- (?<day>\d{1,2}) (?<month>[A-Za-z]{3}) (?<year>\d{4})/`
- Continuation lines must use exactly **2 spaces** — anything else terminates the note.
- `# Month YYYY` section headers in `til.md` are cosmetic; they are not parsed.
- Each note's anchor comes from the text of its first link, so make that link text descriptive.

## Automation

### build-site.js

Parses `til.md` and generates a full static site in `_site/`:
- Home page with the latest notes
- Weekly pages with notes grouped by week (notes sorted newest-first)
- Tag pages grouping notes by hashtag
- Redirect stubs for retired article URLs
- RSS feed (`rss.xml`)

### CI/CD Pipeline (`.github/workflows/build.yml`)

Triggers:
- Push to `main`
- Weekly cron: every Sunday at 00:00 UTC
- Manual `workflow_dispatch`

Steps:
1. **Checkout**
2. **`npm install`** — install dependencies
3. **`node build-site.js`** — generate static site
4. **Deploy to GitHub Pages** via `upload-pages-artifact` + `deploy-pages`

## Notes for AI Assistants

- **Adding content**: Add notes to `til.md` using the `- DD Mon YYYY.` format. Don't create standalone article files; long write-ups go to the main site.
- **Do not edit `_site/`** — it is generated by `build-site.js` and deployed by CI.
- **Date format is strict**: `DD Mon YYYY` (e.g., `20 Feb 2026`). The parser uses the regex `/^- (?<day>\d{1,2}) (?<month>[A-Za-z]{3}) (?<year>\d{4})/`.
- **Continuation lines** in `til.md` must use exactly 2-space indentation; anything else terminates the note.
- **Backdated notes**: `post-mastodon.py` skips new entries dated more than 14 days ago, so backfills don't get tooted.
